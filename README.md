# VaultView

A browser-based banking dashboard and fraud monitoring demo built with plain HTML, CSS, and JavaScript. It uses fictional local sample data only.

## Open the application

1. Open this folder in VS Code.
2. In VS Code Explorer, right-click `index.html` and choose **Open with Live Server** if you have the Live Server extension installed.
3. Or open `index.html` directly from File Explorer in Chrome or Edge.

No Node.js, npm install, or PowerShell script setting is required.

## Demo interactions

- Filter transactions by risk level.
- Create a simulated transfer. Amounts of ₹50,000 or more, and transfers marked international, create a critical alert.
- Freeze or unfreeze the sample card.
- Review, dismiss, or open the mock dispute flow for a flagged transaction.

The app does not connect to a bank or move money.
